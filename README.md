# Peaks Cinema Booking System

A comprehensive movie theater booking and management system built with PHP.

## Features

- **User Authentication:** Secure login and registration (Google OAuth support).
- **Movie Selection:** Browse current and upcoming movies, mood finder integration.
- **Seat Booking:** Interactive seat selection system.
- **Payment Processing:** Integrated payment options.
- **User Dashboard:** View past and current bookings, manage profile.
- **Staff/Admin Panel:** Manage movies, theaters, malls, queues, and view transactions.
- **Notifications & Reminders:** Automated email notifications using PHPMailer.

## Tech Stack

- PHP
- MySQL
- HTML / CSS / JavaScript
